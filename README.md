# 📱 Aura Otomat — Website

Production website for **Aura Otomat**, a business running an **AI-powered phone-case design vending machine** ("Jet Kılıf"): customers upload a photo, the system turns it into a print-ready case design, and the machine produces it on the spot.

🔗 Live: [auraotomat.com](https://auraotomat.com)

## What I did
- Designed and built the full single-page site: hero, how-it-works flow, benefits, about, product gallery and contact sections
- Responsive layout with scroll-triggered fade-in animations
- Deployed and maintain hosting, domain and business e-mail on Hostinger (migrated from Squarespace)

## Stack
HTML5 · CSS3 · Vanilla JavaScript · Hostinger

## Run locally
Open `index.html` in any browser — no build step. (Images are embedded, so the file is self-contained.)
